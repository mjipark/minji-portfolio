LUMA REEF

A procedural 3D reef ecosystem that visually evolves based on sentiment-analyzed journal entries, with a fish companion chat powered by the Claude API.

What it does

Each journal entry a user writes is sent to the Claude API for sentiment analysis. The resulting emotional signal drives procedural changes in a 3D reef built with Three.js — coral growth, water color, and fish behavior all shift to reflect the emotional tone of recent entries.

Fish companion chat

A fish character in the scene acts as a conversational companion, also powered by the Claude API, offering reflective responses based on what's been journaled.
