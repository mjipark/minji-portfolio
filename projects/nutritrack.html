What it does

NutriTrack lets users log meals, track BMI, and count steps — all stored locally in the browser with no backend or server required. Built entirely in vanilla JavaScript as a Progressive Web App, it installs and runs like a native app.

AI diet consultant

A rule-based Korean-language diet consultant offers suggestions based on logged nutrition data, giving users guidance without needing a live model connection.
